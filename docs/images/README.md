# 화면 캡처 계획

> 운영 화면 캡처에는 회사 로고 · 실명 · 실제 ECN 번호가 찍혀 있어 그대로 쓰지 않습니다.
> **가상 데이터만 넣은 시험용 인스턴스**에서 새로 찍어 이 폴더에 둡니다.

| 파일 | 화면 | 보여줄 것 |
|---|---|---|
| `demo.gif` | 접수 → 결재 → 적용 → 종결 | README 맨 위 대표 시연 (20~30초) |
| `ecn-stepper.png` | 설계변경 상세 | 10단계 스테퍼와 관문 2개, 진행 차단 이유 표시 |
| `ledger-grid.png` | 관리대장 그리드 | 27열 2단 머리글, 범위 선택 |
| `bom-diff.png` | BOM 대조 | 신규 · 삭제 · 수량 변경 강조 |
| `agent.png` | AI 에이전트 패널 | 질문 → Tool 조회 결과 → 확인 후 쓰기 |
| `ai-autofill.png` | 결재선 · 일정 등 | 「AI 생성」 표식이 붙은 자동 채움 |
| `meeting.png` | 회의록 | 녹음 → 화자 분리 녹취 → 초안 |
| `approvals.png` | 결재함 | 동시 결재 · 통보 · 보류 |
| `dashboard.png` | 대시보드 | 지연 · 특이 사항 · 경고, 일정 |

찍기 전 확인: 로고 · 회사명 · 실명 · 실제 고객사 · 사내 주소(IP) · 메일 주소가 화면에 없는지.
